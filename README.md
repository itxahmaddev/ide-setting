# 🤖 AI Coding

This setup includes several AI-powered development tools.

### GitHub Copilot

AI code completion, chat, and coding assistance.

### Claude Code

An AI coding agent capable of inspecting codebases, editing files, running terminal commands, and working with MCP.

### Cline

AI coding agent for inspecting and modifying projects.

### Continue

Open-source AI coding assistant supporting multiple models and code context.

### Kilo Code

AI coding agent for planning, building, fixing, and refactoring projects.

### Copy4AI

Helps prepare code and dependencies in an AI-friendly Markdown format and apply AI-generated changes.

> 💡 **Tip:** You don't need to actively use every AI extension at the same time. Keep the tools you actually use enabled to avoid unnecessary editor overhead.

# ⚙️ Editor Configuration

The included settings focus on making the editor comfortable for long coding sessions.

### Font

```json
"editor.fontFamily": "'Fira Code', 'Cascadia Code', Consolas, monospace",
"editor.fontLigatures": true,
"editor.fontSize": 15,
"editor.lineHeight": 28
```
